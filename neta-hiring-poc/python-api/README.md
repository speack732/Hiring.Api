# NetaSystems Hiring API

## Database migrations

Configure the MySQL connection string in a local `.env` file:

```env
DATABASE_URL=mysql+pymysql://root:password@localhost:3306/hiring
```

Alembic is configured to load the SQLAlchemy models from `app.models` and use `Base.metadata` from `app.db.base`.

Create a new autogenerated migration:

```powershell
alembic revision --autogenerate -m "initial employee tables"
```

Apply pending migrations:

```powershell
alembic upgrade head
```

Seeded admin user:

```text
email: admin@neta.local
password: Neta1234
```

The admin user is seeded on application startup after migrations have created the `Users` table.

Login with OAuth2 password flow:

```powershell
curl -X POST http://127.0.0.1:8000/auth/login -H "Content-Type: application/x-www-form-urlencoded" -d "username=admin@neta.local&password=Neta1234"
```

On Windows, if Alembic is only installed inside the local virtual environment, use:

```powershell
venv\Scripts\alembic.exe revision --autogenerate -m "initial employee tables"
venv\Scripts\alembic.exe upgrade head
```

The application should not create database tables from `app/main.py`; schema changes are managed through Alembic migrations.
